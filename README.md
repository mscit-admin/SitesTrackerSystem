# نظام متابعة مواقع الاتصالات — GSDN Sites Tracker

نظام ويب لمتابعة مواقع الاتصالات الخاصة بمشروع **شبكة البيانات الحكومية الآمنة (GSDN)** من شركة الجيل الجديد (aat)، عبر **دورة الحياة الكاملة** للموقع:

> التصميم ← الاستحواذ ← المشتريات ← التجهيز المدني ← تركيب البرج ← تجهيز الموقع ← القبول المدني ← الكهرباء (GECOL) ← الفايبر (HLC) ← جاهزية التركيب ← تركيب المعدات ← الإطلاق (On-Air) ← الاختبارات (EIR/PAT) ← القبول الفني ← **التسليم النهائي للتشغيل** ← **التشغيل والصيانة الدورية**.

بُني هذا النظام كأساس (Foundation) قابل للتوسّع مرحلياً، وتم **استيراد بيانات 318 موقعاً** من ملف `GSDN_Master.xlsb` الأصلي.

---

## المزايا الحالية

- **لوحة مؤشرات (Dashboard):** نظرة عامة على التقدّم، قمع دورة الحياة (Lifecycle Funnel)، التوزيع حسب المنطقة، ملخّص المخاطر والصيانة.
- **إدارة المواقع:** قائمة قابلة للبحث والفلترة (المنطقة، الحالة، الدُفعة) + صفحة تفاصيل لكل موقع تعرض الخط الزمني لكل مرحلة، ومعلومات الموقع، والمعدات (TE BOQ)، وجدول الكميات المدنية (CW BOQ)، والمشاكل.
- **إدخال البيانات لكل مرحلة:** شاشات إدخال/تعديل بتبويبات لكل مرحلة من مراحل دورة الحياة (14 مرحلة)، مع إضافة موقع جديد. تُحفظ البيانات في قاعدة البيانات ويُعاد احتساب حالة المراحل ونسبة الإنجاز تلقائياً بعد كل حفظ.
- **وحدة الاستحواذ (Acquisition):** إدارة النقاط الاسمية والمرشّحين (1–3 لكل نقطة) عبر **أربع بوّابات اعتماد** (اعتماد المرشّح ← إذن المسح ← الاعتماد الفني ← الاعتماد النهائي) مع الرفض والعودة للبحث، وقائمة ملّاك الأبراج (المدار/البنية/ليبيانا/LTT/مواطن/أخرى) بأولوية شركات القطاع. عند الاعتماد النهائي يُحوَّل المرشّح إلى **موقع** بمعرّف رسمي جديد ويدخل دورة الحياة تلقائياً.
- **التشغيل والصيانة (O&M):** متابعة ما بعد التسليم — جداول الصيانة الدورية الوقائية، وتسجيل ومتابعة بلاغات الصيانة التصحيحية.
- **سجل المخاطر (Risk Register):** 25 مخاطرة مع الاحتمال والأثر والدرجة والمستوى والاتجاه.
- **الإعدادات (Settings):** إدارة القوائم المرجعية — أنواع المعدات والشركات المصنّعة — التي تُستخدم عند تحديد معدات المرشّح في الاستحواذ (كمية + شركة مصنّعة + نوع معدة قبل الاعتماد).
- **تحديث المواقع من إكسل:** زر «تحديث من إكسل» في شاشة المواقع يرفع ملف GSDN Master (`.xlsb` أو `.xlsx`) ويطابق المواقع بالمعرّف — الموجود يُحدَّث والجديد يُضاف، مع إعادة احتساب المراحل تلقائياً — إضافةً إلى زر «تحميل ملف الإكسل» الأصلي.
- **تحديد الإحداثيات من الخريطة:** بجانب حقول خط الطول/العرض (في معلومات الموقع، والنقطة الاسمية، والمرشّح) زر «اختر من الخريطة» يفتح خريطة تفاعلية (Leaflet + OpenStreetMap) في نافذة منبثقة — نقر/سحب لتحديد الموقع فتُعبّأ الإحداثيات تلقائياً. (عرض بلاطات الخريطة يتطلّب اتصال إنترنت في المتصفّح.)
- واجهة **عربية RTL** بالكامل.

## التشغيل محلياً

المتطلبات: Node.js 18+ و(اختيارياً) Python 3 لإعادة الاستيراد من Excel.

```bash
# 1) تثبيت الحزم
npm install

# 2) توليد عميل Prisma + إنشاء قاعدة البيانات + استيراد البيانات
npm run setup

# 3) تشغيل بيئة التطوير
npm run dev
# ثم افتح http://localhost:3000
```

### أوامر مفيدة

```bash
npm run dev        # تشغيل التطوير
npm run build      # بناء الإنتاج
npm start          # تشغيل الإنتاج
npm run db:seed    # إعادة تعبئة البيانات
npm run db:reset   # تصفير قاعدة البيانات وإعادة التعبئة
```

## إعادة الاستيراد من ملف Excel جديد

عند تحديث ملف الماستر، ضع النسخة الجديدة في `data/source/GSDN_Master.xlsb` ثم:

```bash
pip install -r scripts/requirements.txt
python3 scripts/extract_xlsb.py          # يُنتج data/sites.json و data/risks.json
npm run db:seed                          # يُعيد تحميلها في قاعدة البيانات
```

## الانتقال إلى الإنتاج (PostgreSQL)

في `prisma/schema.prisma` غيّر `provider` إلى `"postgresql"`، وفي `.env` عيّن `DATABASE_URL` لخادم Postgres، ثم:

```bash
npx prisma migrate deploy && npm run db:seed
```

## بنية المشروع

```
app/                 # صفحات Next.js (لوحة المؤشرات، المواقع، الصيانة، المخاطر)
  maintenance/       #   صفحة O&M + Server Actions للبلاغات
  sites/[id]/        #   تفاصيل الموقع
components/          # مكوّنات الواجهة (الشريط الجانبي، الخط الزمني، البطاقات…)
lib/
  lifecycle.ts       # منطق دورة الحياة: تعريف المراحل + اشتقاق الحالة والتقدّم
  queries.ts         # استعلامات قاعدة البيانات
  prisma.ts, format.ts
prisma/
  schema.prisma      # نموذج البيانات
  seed.ts            # سكربت الاستيراد إلى قاعدة البيانات
scripts/
  extract_xlsb.py    # تحويل .xlsb → JSON
data/                # sites.json + risks.json (مصدر التعبئة) + source/*.xlsb
```

## نموذج البيانات (باختصار)

- **Site** — هوية الموقع + ملخّص محسوب (المرحلة الحالية، نسبة الإنجاز، الحالة) + تفاصيل غنية (JSON) لجداول الكميات والمعدات.
- **Milestone** — سجل موحّد لكل مرحلة من مراحل دورة الحياة الـ16 (يشمل مرحلة التشغيل والصيانة).
- **Issue** — المشاكل والملاحظات لكل موقع.
- **Risk** — سجل المخاطر على مستوى المشروع.
- **MaintenanceTicket / PreventiveMaintenance** — بلاغات الصيانة التصحيحية والصيانة الوقائية الدورية (طور ما بعد التسليم).
- **User** — المستخدمون والأدوار (تُفعّل المصادقة في مرحلة لاحقة).

## خارطة الطريق (التوسّع المرحلي)

هذا الإصدار هو **الأساس**. المراحل التالية المقترحة:

1. **المصادقة والصلاحيات (Auth & RBAC):** تسجيل دخول وأدوار للفرق (تصميم / مدني / معدات / تشغيل).
2. ~~تحرير البيانات من الواجهة~~ ✅ **تم:** شاشات إدخال بيانات لكل مرحلة + إضافة موقع جديد.
3. **سجل التدقيق (Audit Log):** تتبّع من غيّر ماذا ومتى.
4. **التقارير والتصدير:** تصدير Excel/PDF، تقارير أسبوعية/يومية (Weekly Plan / Daily Progress).
5. **الخريطة الجغرافية:** عرض المواقع على خريطة تفاعلية.
6. **التنبيهات:** إشعارات للصيانة المتأخرة والمراحل المتعثّرة.
